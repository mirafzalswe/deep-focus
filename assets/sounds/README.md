# Звуки Deep Focus

Сюда кладутся mp3 для библиотеки звуков. В сборке папка копируется в ресурсы приложения (`resources/assets/sounds`).
Пока файла нет, звук виден в разделе «Звуки» с пометкой «файл не добавлен» и не играет.

Используйте только записи, на которые у вас есть права (своя запись, CC0, купленная лицензия, разрешение автора).

## Где ещё ищется файл

1. `%APPDATA%\Deep Focus\sounds\<имя>.mp3|.ogg|.wav|.m4a` — сюда кладёт файл кнопка «Выбрать файл» у звука в разделе «Звуки»; этот файл важнее файла из этой папки.
2. `assets/sounds/<имя>.mp3` — эта папка.

Свои звуки (кнопка «Добавить свой звук», mp3/ogg/wav/m4a) копируются в `%APPDATA%\Deep Focus\sounds` и появляются в категории «Свои».

## Советы по файлам

- Длина от 1 до 10 минут. Тишина в начале и в конце обрезается автоматически, стык петли сглаживается кроссфейдом около 1,5 с.
- Ровный фон без резких событий (гром, голоса) зацикливается незаметнее.
- 128–192 кбит/с достаточно; файл, который не удаётся декодировать, помечается «файл повреждён», остальные дорожки играют.
