# Deep Focus — что осталось

Последняя сборка: `.autopilot/2026-10-27-deep-focus/` — десктоп-приложение для Windows: плавающий таймер поверх окон, блокировка сайтов через системный прокси, микшер звуков, задачи, аналитика, установщик.

## Договорились — не пересматривать

- Расширения браузера нет: «расширения для браузера пока ненужно» (R70, R128, R142, R156i). Блокировка — только целыми доменами: «1)да»
- Права администратора не запрашиваются никогда: «так не спрашивать права админа должен рработать без этого» — поэтому PAC в HKCU, а не hosts (R72, R159i)
- Звуки природы и атмосферы — mp3 пользователя: «я сам добавлю загружу тебе mp3 файлы дождя море и тд»; шумы генерируются приложением (R155i)
- Обновления — GitHub Releases, релизы публикует пользователь: «4) да» (R150)
- Интерфейс на русском (по умолчанию) и английском; macOS не собирается — озвучено в брифинге, возражений не было (R157i, R02)

## Не доделано

- macOS — не собирается и не тестируется (R02)
- Проверка на Windows 11 и с двумя мониторами — только ручной чек-лист `docs/manual-checklist.md` (R152)
- Физическое перетаскивание и ресайз виджета мышью и нажатие горячих клавиш при приёмке не проверены: экран был заблокирован (проверено автотестами через системные сообщения)

## Известные баги

- Статус блокировки не перепроверяется после включения: если другая программа перезапишет прокси или упадёт заглушка, статус останется «активна»
- При ошибке блокировки повторная попытка включения раз в минуту — системные настройки прокси дёргаются, пока ошибку не устранят
- После принудительного завершения процесса в прокси остаётся адрес выключенной заглушки до следующего запуска (интернет работает напрямую)
- Strict: выход с «остановить сессию» не останавливает её (сессия сохраняется для восстановления); Ctrl+Alt+E в Strict молча не срабатывает
- Strict: переключатель «блокировка на паузе» во вкладке Settings → Timer активен, изменение отклоняется с ошибкой
- `--cleanup` при удалении поднимает остальные модули раньше — восстановленная сессия может мелькнуть виджетом
- Импорт бэкапа доверяет полю `builtin` из файла
- «Удалить все данные» при `DEEPFOCUS_USER_DATA` на общей папке удалит там чужую `sounds/`; нет интеграционного теста на отказ удаления при невозвращённом прокси
- При выходе с «остановить» причина сессии `stopped`, а не `appQuit`
- Часовой mp3 декодируется целиком — окно звука может упасть по памяти; ошибка добавления своего звука не показывается
- После окончательного падения окна звука открытие Sounds ждёт 10 с
- Уведомление «клики насквозь восстановлены» идёт мимо настроек уведомлений
- Переименование задачи во время сессии не обновляет название в Expanded-виджете
- `UpdateService.installOnQuit()` нигде не вызывается — обновление ставится по кнопке
