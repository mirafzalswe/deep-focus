# Спецификация: Deep Focus

## Задача

«Я сажусь работать — и через десять минут уже в YouTube. Таймер в отдельном окне я не вижу, пока не открою его, а блокировщик, музыка и учёт времени живут в разных программах. Хочу один раз нажать “старт” — и чтобы время было перед глазами поверх любой программы, отвлекающие сайты не открывались, играл дождь, а потом я видел, сколько на самом деле проработал».

## Решение

Приложение для Windows, которое живёт в трее. Пользователь выбирает задачу (или не выбирает) и жмёт «Старт». Поверх всех окон появляется маленький полупрозрачный таймер, который можно двигать, растягивать, сделать «прозрачным для мыши» и спрятать горячей клавишей. На время работы отвлекающие сайты перестают открываться во всех браузерах, которые следуют системным настройкам прокси. Начинают звучать выбранные звуки. По окончании интервала приложение предлагает отдых, а потом следующий цикл. Каждая сессия честно попадает в статистику: отдельно активное время, пауза, время сна компьютера и досрочные остановки. После сбоя или перезагрузки таймер продолжает с правильным остатком. Всё хранится локально, без аккаунта и без прав администратора.

### §4 Блокировка сайтов

Механизм — **системный прокси текущего пользователя через PAC-файл** (решение пользователя: без расширения и без прав администратора). Приложение поднимает на `127.0.0.1` маленький сервер: он отдаёт `proxy.pac` и работает «заглушкой» для заблокированных доменов. Для HTTP заглушка отвечает страницей «Заблокировано Deep Focus», для HTTPS (CONNECT) отвечает отказом, и браузер показывает ошибку соединения. Всё незаблокированное идёт напрямую (или через исходный прокси пользователя), мимо приложения.

## Решения по реализации

- **electron-vite + React + Tailwind v4**: один конфиг на main/preload/три renderer-входа (app, widget, audio).
- **SQLite через better-sqlite3** в main (синхронный, быстрый, WAL). Нативный модуль собирается под Electron через `@electron/rebuild` / prebuild. Если сборка в этой среде невозможна, берём sql.js (WASM) с атомарной записью файла. Решает T01 и записывает в `interfaces.md`.
- **Таймер в main** на абсолютных временах; `setInterval(250)` только рассылает снимки. Сон и пробуждение — через `powerMonitor` `suspend`/`resume`; выключенное приложение — по heartbeat.
- **Виджет**: frameless transparent BrowserWindow, `alwaysOnTop` уровня `screen-saver`, `skipTaskbar`, `focusable: false` в click-through. Общая прозрачность — `setOpacity`, фон — CSS. Click-through — `setIgnoreMouseEvents(true, {forward: true})`.
- **Блокировка**: PAC через HKCU + локальный сервер-заглушка (Node `http`, `127.0.0.1`, случайный свободный порт, адрес PAC с `?v=<время>`, чтобы браузеры перечитали). Запись реестра — `reg.exe add/delete` в HKCU, уведомление WinINET — `InternetSetOption(SETTINGS_CHANGED, REFRESH)` через одноразовый PowerShell с P/Invoke. Проверка — `[System.Net.WebRequest]::GetSystemWebProxy()`. Почему не hosts: нужны права администратора, пользователь отказался. Почему не расширение: пользователь отказался.
- **Звук**: скрытое окно `audio` с Web Audio; файлы отдаются ему по собственному протоколу `df-sound://` (только из двух разрешённых папок). Шумы — `AudioBuffer` 10 с с бесшовной стыковкой, коричневый — интегрированный белый, розовый — фильтр Пола Келлета.
- **Уведомления** — Electron `Notification` (тосты Windows), `silent` по настройке; AppUserModelID задан.
- **Обновления** — `electron-updater`, провайдер GitHub, `autoDownload: false`.
- **Тесты** — Vitest (чистая логика, движок таймера на фиктивных часах), Playwright `_electron` для e2e, PowerShell P/Invoke для проверки стилей окна.

Схема БД: `settings(key PK, value JSON)`, `timer_presets`, `sound_presets(tracks JSON)`, `block_rules(schedule JSON)`, `projects`, `tasks`, `sessions` (поля `SessionRecord`), `achievements(id, kind 'daily'|'weekly'|'project', period, achievedAt, valueMin)`, `recovery(id=1, json, updatedAt)`, `kv` (сохранённые исходные настройки прокси, версия схемы).
