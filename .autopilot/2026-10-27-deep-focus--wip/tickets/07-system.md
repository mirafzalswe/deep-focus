## Что должно заработать

Все пять глобальных горячих клавиш переназначаются, а системные, занятые и дублирующие сочетания отклоняются. Тихие уведомления Windows приходят о шести событиях, каждое включается отдельно. Приложение живёт в трее, закрытие окна его прячет, автозапуск с Windows включается по желанию. «Выход» спрашивает, остановить активную сессию или продолжить её при следующем запуске. Home собран полностью: звуковой профиль, статус блокировки, сводка дня. В General видны тема, язык, автозапуск, трей, уведомления, папка данных, резервная копия и удаление всех данных.

## Из брифа, дословно

> «Все уведомления должны быть ненавязчивыми и настраиваемыми.» · «Начало сессии. Завершение рабочего интервала. Начало перерыва. Завершение перерыва. Достижение дневной цели. Ошибка блокировки сайтов.»
> «Глобальные горячие клавиши: Запуск или пауза. Показ или скрытие плавающего таймера. Переключение интерактивности виджета. Завершение сессии. Отключение или включение фоновых звуков. Все сочетания должны настраиваться. Приложение должно проверять конфликты с системными и другими глобальными клавишами.»
> «Работу в системном трее. Минимизацию без завершения процесса. Запуск вместе с Windows по желанию пользователя. Возможность полностью завершить приложение.»
> «При завершении приложения пользователь должен понимать, будет ли активная сессия остановлена или восстановлена при следующем запуске.»
> «Главный экран должен включать: Текущий режим. Основной таймер. Кнопку запуска. Текущую задачу. Выбор звукового профиля. Статус блокировки. Краткую статистику за день.» · «Второстепенные настройки не должны перегружать главный экран.»
> General: «Тема. Язык. Запуск вместе с Windows. Системный трей. Уведомления. Локальное хранение. Резервное копирование настроек.» · «Предоставлять пользователю контроль над локальными данными.»

## Критерии приёмки

- [ ] `hotkeys/validate.ts` (тесты): системные сочетания, дубликат внутри приложения, пустое значение = отключено; `register` вернул false → «занято другой программой», прежнее сочетание остаётся рабочим
- [ ] Пять действий по горячим клавишам работают (по умолчанию Ctrl+Alt+Space/W/I/E/M), переназначаются в Settings полем записи сочетания; временные регистрации таска 03 заменены
- [ ] Уведомления о шести событиях, каждое отдельно включается; `silent` по настройке; заданы AppUserModelID и имя
- [ ] Трей: иконка, подсказка с остатком, меню (открыть, старт/пауза, показать таймер, интерактивность, поверх окон, выход); закрытие окна прячет в трей при `closeToTray`
- [ ] Автозапуск с Windows через `setLoginItemSettings`, запуск свёрнутым в трей
- [ ] Выход при активной сессии: диалог «Остановить сессию» / «Продолжить при следующем запуске» + «запомнить»; в обоих случаях блокировка снимается и это сказано; выбор «продолжить» действительно восстанавливается (e2e)
- [ ] Home: выбор звукового профиля, статус блокировки, сводка дня (Deep Work сегодня, сессии, прогресс цели) без второстепенных настроек
- [ ] General: тема, язык, автозапуск, трей, `quitBehavior`, уведомления, путь к данным и журналу, «Открыть папку»
- [ ] Резервная копия: экспорт/импорт JSON через диалог файла; битый файл → сообщение, настройки нетронуты (e2e или тест)
- [ ] «Удалить все данные»: подтверждение вводом слова, снимается блокировка, удаляются БД и свои звуки, приложение перезапускается чистым
