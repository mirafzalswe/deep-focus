## Что должно заработать

В разделе Sounds есть библиотека: природа, шумы, атмосфера. Несколько звуков играют одновременно, у каждого своя громкость, есть общая громкость, петли без щелчков. Сохраняются свои комбинации и есть готовые пресеты. При старте сессии включается рабочий профиль, на перерыве звук ведёт себя по настройке, остановка идёт плавным затуханием. Белый, розовый и коричневый шум приложение генерирует само. Остальные звуки берутся из mp3, которые пользователь положит в `assets/sounds/` или добавит кнопкой. Пока файла нет, звук виден с пометкой «файл не добавлен».

## Критерии приёмки

- [ ] Скрытое окно audio с Web Audio; команды только из main; падение окна → пересоздание, таймер не страдает
- [ ] Поиск файла: `userData/sounds/<id>.*`, затем `assets/sounds/<id>.mp3` (в сборке — extraResources); отдача через `df-sound://` только из этих двух папок (тест на попытку выйти за папку)
- [ ] `availability()`: отсутствующий файл → «файл не добавлен», не декодируется → «файл повреждён»; остальные дорожки играют
- [ ] Генераторы белого, розового и коричневого шума без файлов; петля без щелчка на стыке
- [ ] Файловые петли: обрезка тишины по краям, кроссфейд около 1.5 с
- [ ] Несколько дорожек одновременно с независимой громкостью и включателем; общая громкость; mute
- [ ] Остановка — затухание `fadeOutMs`
- [ ] Встроенные пресеты Rain Focus, Ocean Focus, Forest, Brown Noise, Coffee Shop, Silent Focus; свои — сохранить, переименовать, удалить
- [ ] Рабочий и отдыхающий профили; `autoStartOnSession`; на перерыве — stop/continue/switch/lower (тест реакции на события таймера)
- [ ] «Добавить свой звук» (mp3/ogg/wav/m4a) копирует файл в `userData/sounds` и показывает его в категории «Свои» (A01 → R80)
- [ ] Настройки и пресеты переживают перезапуск
- [ ] `assets/sounds/README.md` с точными именами файлов; раздел Sounds и вкладка Settings → Sounds
