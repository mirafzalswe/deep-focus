## Что должно заработать

`npm run dev` открывает окно Deep Focus: графитовая тема, боковая навигация из семи разделов (Home, Timer, Sounds, Blocker, Tasks, Analytics, Settings), переключение языка ru/en и темы dark/light/system без перезапуска. Данные лежат в SQLite в `userData`, настройки сохраняются и переживают перезапуск. Есть журнал ошибок. Всё остальное — заглушки модулей с именами и IPC из `interfaces.md`, чтобы следующие таски заполняли только свои папки.

## Критерии приёмки

- [ ] electron-vite + React + Tailwind + TypeScript strict; три renderer-входа (app, widget, audio); `npm run dev`, `npm run build`, `npm run check` (tsc + vitest + eslint) работают; версии зафиксированы точно
- [ ] SQLite (better-sqlite3 под Electron, либо sql.js с атомарной записью — выбор записан в `interfaces.md`) с миграциями: все таблицы из «Решений по реализации»; тест репозиториев на временном файле
- [ ] Повреждённый файл БД переименовывается в `.corrupt-<дата>`, создаётся новый, приложение запускается
- [ ] `SettingsManager`: `get/patch/on('change')`, глубокое слияние, валидация (неверное значение → `SettingsError`, сохранённое не меняется), значения по умолчанию из `defaults.ts`; экспорт/импорт бэкапа с проверкой схемы; тесты
- [ ] `src/shared/types.ts`, `ipc.ts`, `defaults.ts` — все типы, каналы и значения по умолчанию из `interfaces.md` (включая встроенные пресеты таймера, звуков, правила блокировки, библиотеку звуков, сид-проекты)
- [ ] Preload: `window.deepFocus` со всеми доменами; каждый домен в своём файле; обработчики main валидируют аргументы; contextIsolation, sandbox, nodeIntegration=false, CSP без `unsafe-eval`
- [ ] Каркас всех модулей main из `interfaces.md` с регистрацией в `index.ts`; инициализация каждого обёрнута — исключение в одном модуле логируется и не мешает остальным (тест)
- [ ] Single-instance lock: второй запуск показывает первое окно
- [ ] Оболочка: навигация из 7 разделов, вкладки Settings (Timer, Floating Widget, Website Blocker, Sounds, General) как пустые компоненты в своих файлах; дизайн-токены (графит, приглушённые синий и зелёный) в одном месте
- [ ] Тема dark/light/system и язык ru/en переключаются в General без перезапуска; i18n-словари по доменам, отсутствующий ключ — ошибка типов
- [ ] Logger пишет в `userData/logs/deepfocus.log` с ротацией; `uncaughtException`/`unhandledRejection` в main логируются
- [ ] Ни одного сетевого запроса наружу в коде
- [ ] `AGENTS.md`: таблица «Команды» заполнена реальными командами
