## Что должно заработать

`npm run dist` собирает установщик Windows, который ставится без прав администратора, создаёт ярлыки и при удалении возвращает системные настройки прокси. Приложение умеет проверять обновления на GitHub Releases, когда источник будет указан, а до этого честно пишет, что источник не настроен. Есть README, описание ограничений, ручной чек-лист для Windows 11 и двух мониторов и таблица соответствия семнадцати сценариев готовности автоматическим проверкам.

## Критерии приёмки

- [ ] Иконка приложения и трея (своя, не чужой бренд) в `resources/`
- [ ] `npm run dist` → NSIS-установщик per-user без UAC; `extraResources` включает `assets/sounds`; деинсталлятор вызывает `DeepFocus.exe --cleanup`; установка и запуск собранного приложения проверены на этой машине
- [ ] `UpdateService` на electron-updater (GitHub, `autoDownload: false`); `[GITHUB_OWNER]/[GITHUB_REPO]` не заполнены → кнопка «Проверить обновления» показывает «источник не настроен», сетевого запроса нет; при настроенном источнике — проверка, скачивание по кнопке, установка при выходе
- [ ] `README.md` (ru): установка, первый запуск, разделы, горячие клавиши, куда класть mp3, где данные
- [ ] `docs/limitations.md`: полноэкранные приложения, браузеры и программы без системного прокси, нельзя выбрать отдельные браузеры, поддомены и связанные сервисы, открытые вкладки, корпоративный PAC, сон, неподписанный установщик и SmartScreen
- [ ] `docs/manual-checklist.md`: Windows 11 и два монитора — пошагово
- [ ] `tests/e2e/acceptance.spec.ts` + `docs/acceptance.md`: каждый из 17 сценариев §17 брифа сопоставлен с автоматической проверкой (или ручным пунктом чек-листа с причиной); весь набор проходит на этой машине
- [ ] Проверки безопасности: `npm audit --omit=dev` без high/critical; тест, что окна созданы с contextIsolation/sandbox и без nodeIntegration
