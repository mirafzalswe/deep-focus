# Ограничения и исключения

Deep Focus работает без прав администратора и без расширений браузера. Из этого следуют ограничения ниже.

## Плавающий виджет и полноэкранные приложения

Виджет держится поверх обычных окон уровнем «поверх всех окон». Абсолютную видимость поверх **каждого** приложения гарантировать нельзя: эксклюзивный полноэкранный режим (часть игр и видеоплееров) может скрывать виджет. Помогает режим «в окне без рамки» в самой программе. Окна, запущенные от администратора, Windows тоже может ставить выше виджета.

## Блокировка сайтов

Механизм — системный прокси текущего пользователя через PAC-файл: меняются только значения в `HKCU\Software\Microsoft\Windows\CurrentVersion\Internet Settings`. Файл hosts, HKLM, брандмауэр и защита Windows не затрагиваются.

- **Браузеры и программы без системного прокси.** Блокировка действует во всех браузерах и программах, которые следуют системному прокси Windows. Программа или браузер со своим прокси, VPN с собственной маршрутизацией или встроенным обходом (например, свой DNS-over-HTTPS с прокси) её обходит. Блокируются только заблокированные домены, остальной трафик идёт как обычно.
- **Нельзя выбрать отдельные браузеры.** Правило применяется ко всем браузерам сразу; «блокировать только в одном браузере» невозможно.
- **Поддомены и связанные сервисы.** Блокировка домена закрывает все его поддомены и сервисы на нём, в том числе вход через этот домен на других сайтах. Отдельные страницы (например, только `youtube.com/shorts`) заблокировать нельзя: если вписать адрес с путём, блокируется весь домен — приложение предупреждает об этом при добавлении.
- **Открытые вкладки.** Вкладки, открытые до начала блокировки, могут работать до перезагрузки страницы: браузер держит уже установленные соединения.
- **Корпоративный PAC.** Если в системе уже настроен свой PAC (например, на работе), приложение его не заменяет, а сообщает, что блокировка недоступна. Заданный вручную прокси сохраняется: незаблокированные сайты идут через него.
- **Системные адреса** (`localhost`, IP-адреса, `*.microsoft.com`, `*.windowsupdate.com` и др.) заблокировать нельзя — защита от поломки Windows.
- **Возврат настроек.** Исходные значения прокси сохраняются до первого изменения и возвращаются при выключении блокировки, выходе, после сбоя (при следующем запуске) и при удалении (`--cleanup` деинсталлятора). Если компьютер выключили посреди сессии, значения вернутся при следующем запуске приложения.

## Сон и выключение

Во время сна компьютера таймер не считает активное время: время сна записывается отдельно и в активное не входит. Если приложение закрыто аварийно или компьютер выключили, при следующем запуске сессия восстанавливается по последнему сохранению с пометкой «восстановлена»; интервал, закончившийся за это время, засчитывается по расчёту.

## Неподписанный установщик и SmartScreen

Установщик не подписан сертификатом code signing (нужны аккаунт и сертификат владельца проекта). Windows SmartScreen при первом запуске покажет «Windows защитила ваш компьютер»: нажмите «Подробнее → Выполнить в любом случае». Подпись кода убирает предупреждение. Некоторые антивирусы осторожничают с неподписанными приложениями на Electron.

## Прочее

- Только Windows (10 и 11); macOS в этой сборке не поддерживается.
- Проверка обновлений — только GitHub Releases и только по кнопке; пока источник не указан, сетевых запросов нет.
- Автоматически проверено на Windows 10; Windows 11 и два монитора — по ручному чек-листу [manual-checklist.md](manual-checklist.md), логика мониторов покрыта тестами.
