# Ручная проверка: Windows 11 и два монитора

Автоматически проверено только на Windows 10. Пройдите пункты на Windows 11 и на компьютере с двумя мониторами (лучше с разным масштабом, например 100% и 150%). Результат отмечайте в квадратных скобках.

## Подготовка

1. Запустите `Deep Focus Setup <версия>.exe`. [ ] UAC не появился. [ ] Есть ярлыки на рабочем столе и в «Пуске».
2. [ ] SmartScreen показал предупреждение, «Подробнее → Выполнить в любом случае» запускает установщик.
3. Запустите приложение. [ ] Открылось главное окно. [ ] В трее значок-кольцо.

## Виджет и два монитора

4. Нажмите «Старт». [ ] Появился виджет. Перетащите его на второй монитор. [ ] Размер читаем при другом масштабе.
5. Измените размер уголком. Выйдите через трей и запустите снова. [ ] Виджет на том же мониторе, в том же месте и того же размера.
6. Привязка к углу в настройках виджета. [ ] Виджет встаёт в угол рабочей области, панель задач не перекрыта.
7. Выйдите из приложения, отключите второй монитор, запустите. [ ] Виджет на доступном экране. Верните монитор. [ ] Политика «основной / ближайший» работает как выбрана.
8. Отключите второй монитор при работающем приложении. [ ] Виджет перенёсся без перезапуска.

## Поверх окон

9. Откройте Блокнот, браузер, проводник. [ ] Виджет остаётся поверх. Выключите и включите «поверх всех окон». [ ] Переключение работает.
10. Откройте видео в браузере на весь экран (F11). Виден ли виджет: [ ] да [ ] нет (допустимо, см. limitations.md).
11. Ctrl+Alt+I. [ ] Клики проходят сквозь виджет. Ctrl+Alt+I ещё раз. [ ] Виджет снова реагирует. [ ] То же из меню трея.
12. Ползунок прозрачности. [ ] Цифры читаются при 30%.

## Таймер

13. Запустите сессию в 1 минуту (свой пресет). [ ] Идёт отсчёт. [ ] В конце пришло уведомление Windows 11.
14. Во время сессии переведите компьютер в сон на 2–3 минуты. [ ] После пробуждения время сна не вошло в активное (Аналитика → «Точность учёта»).
15. Во время сессии завершите `Deep Focus.exe` в диспетчере задач и запустите снова. [ ] Сессия восстановлена с пометкой.

## Блокировка

16. Включите блокировку. [ ] Показано согласие; пока не нажато «Включить», настройки прокси не менялись.
17. Старт Focus. [ ] `youtube.com` в Edge и Chrome показывает страницу-заглушку. После стопа [ ] сайт открывается.
18. Во время блокировки выйдите через трей. [ ] Сайт открывается; «Параметры → Сеть и Интернет → Прокси» без адреса Deep Focus.
19. Удалите приложение. [ ] Параметры прокси такие же, как до установки.

## Звук, трей, автозапуск

20. Положите `rain.mp3` в `resources\assets\sounds`. [ ] В «Звуки» пометка исчезла, дождь играет вместе с шумом, громкости независимы.
21. Включите автозапуск, выйдите из Windows и войдите. [ ] Приложение стартовало свёрнутым в трей.
22. [ ] Тема и язык переключаются без перезапуска. [ ] Уведомления приходят от «Deep Focus» и видны в Центре уведомлений.

## Журнал

23. [ ] В `%APPDATA%\Deep Focus\logs\deepfocus.log` нет неожиданных ошибок после прохода.
