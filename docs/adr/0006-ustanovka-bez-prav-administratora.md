# Установка для текущего пользователя, без прав администратора

## Контекст

Пользователь поставил условие: ни один сценарий не должен требовать прав администратора. Бриф требует установщик (R149), автозапуск (R116) и удаление с восстановлением системных настроек (R141). Сертификата для подписи кода у пользователя нет.

## Решение

Приложение ставится NSIS-установщиком в профиль текущего пользователя без запроса UAC. Ничего не пишется в HKLM, Program Files и hosts. Автозапуск живёт в HKCU. Деинсталлятор вызывает приложение с флагом очистки, которое возвращает системные настройки прокси. Установщик не подписан.

## Почему

- **Установка на всю машину** (Program Files, HKLM) отвергнута: запрашивает UAC, пользователь отказался.
- **Подписать установщик** отвергнуто на этом этапе: нужны аккаунт и сертификат пользователя, их нет.
- Установка в профиль согласуется с остальными решениями: PAC в HKCU (ADR 0001) и обновления без повышения прав (ADR 0007).

## Последствия

- Windows SmartScreen покажет предупреждение об неизвестном издателе; это описано в документации, а не устранено.
- Приложение нельзя поставить сразу всем пользователям одного компьютера.
- Корректное удаление зависит от того, что флаг очистки отработает; если деинсталлятор запущен при сбое, возможен хвост в настройках прокси, который чинится при следующем запуске приложения.
- Нативные модули берутся из готовых сборок: на машине нет Visual Studio, поэтому пересборка отключена.
- Автозапуск проверяется только на установленной сборке, не на запуске из исходников.
