# Звук в скрытом окне, шумы генерируются, записи приносит пользователь

## Контекст

Бриф требует микшер из нескольких фоновых звуков с бесшовными петлями (R78–R87) на Web Audio и записи с подходящей лицензией (R81). Скрытие виджета и падение любого окна не должно прерывать звук (R58, R148). Сетевых запросов, кроме проверки обновлений, быть не должно (R137).

## Решение

Воспроизведение идёт в отдельном скрытом окне со звуковым движком; main управляет им командами и принимает статус только от него. Белый, розовый и коричневый шум приложение генерирует само. Природные и атмосферные звуки — mp3, которые кладёт пользователь, плюс кнопка «Добавить свой звук». Файлы отдаются окну по собственному протоколу только из двух разрешённых папок.

## Почему

- **Звук в главном окне или виджете** отвергнут: их можно закрыть, спрятать в трей или пересоздать при сбое, а звук должен продолжаться. Скрытое окно живёт отдельно и пересоздаётся без вмешательства в таймер.
- **Звук в main** невозможен: Web Audio существует только в окне.
- **Встроить записи в приложение** отвергнуто: подходящая лицензия есть только у пользователя («я сам добавлю mp3»); взять чужие записи — риск нарушения лицензии (R81).
- **Скачивать звуки из сети** отвергнуто: противоречит требованию не ходить в сеть (R137).
- **Прямой доступ окна к файловой системе** отвергнут: нарушил бы изоляцию (ADR 0003). Протокол с белым списком папок оставляет окну только чтение звуков.
- Шумы генерируются, потому что им не нужна лицензия и файлы.

## Последствия

- Пока пользователь не положил mp3, двенадцать звуков видны с пометкой «файл не добавлен» и не играют. Это известный пробел, не готовность функции целиком (R80 остаётся заглушкой).
- Имена файлов жёстко заданы библиотекой; ошибка в имени выглядит как отсутствующий файл.
- Окно звука создаётся по требованию и закрывается вместе с последним окном приложения; при работе из трея это нужно проверять отдельно.
- Лицензионная чистота записей лежит на пользователе.
- Собственный протокол — дополнительная поверхность атаки, её нужно держать узкой.
