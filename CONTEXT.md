# Deep Focus

Настольное приложение для Windows: таймер для сосредоточенной работы поверх всех окон, блокировка отвлекающих сайтов, фоновые звуки и учёт времени.

## Язык

**Интервал**:
Один отрезок таймера определённого вида: Focus, короткий или длинный перерыв.
_Избегать_: этап, период, отсчёт

**Сессия**:
Запись об одном завершённом интервале в истории: сколько он длился, чем закончился, к какой задаче относится. Пишется и для перерывов, но в речи «сессия» обычно значит рабочую.
_Избегать_: подход, помидор

**Focus**:
Рабочий интервал с блокировкой и звуками. Только он идёт в статистику Deep Work.
_Избегать_: работа, рабочий режим, концентрация

**Deep Work**:
Время сосредоточенной работы, которое приложение учитывает: сумма активного времени Focus. Свободный Deep Work — режим Focus без автоматических перерывов и без обязательного лимита.
_Избегать_: глубокая работа, продуктивное время

**Перерыв**:
Интервал отдыха после Focus. Короткий идёт после каждого Focus, длинный — после заданного числа Focus подряд (по умолчанию 4).
_Избегать_: пауза, отдых

**Цикл**:
Несколько Focus подряд, завершаемых длинным перерывом. Счётчик цикла не растёт от пропущенного Focus.
_Избегать_: раунд, серия Focus

**Виджет**:
Маленький полупрозрачный таймер в отдельном системном окне поверх всех программ; существует независимо от главного окна. Бывает Compact, Standard и Expanded.
_Избегать_: плавающее окно, оверлей, мини-таймер

**Click-through**:
Состояние виджета, когда клики проходят сквозь него к окну под ним; противоположное — Interactive, когда виджет можно двигать и нажимать. Вернуть интерактивность можно всегда.
_Избегать_: прозрачный для мыши, режим призрака, неинтерактивный

**Правило блокировки**:
Запись «домен + категория + когда действует»; блокирует домен целиком, вместе с поддоменами, а не отдельные страницы.
_Избегать_: фильтр, чёрный список, блок-лист

**Strict Mode**:
Уровень блокировки, при котором снять её во время сессии можно только после ожидания и ввода фразы. Противоположность — Standard, где блокировку выключают кнопкой.
_Избегать_: строгий режим, режим без выхода

**Scheduled Mode**:
Включённое расписание у правил блокировки: они действуют в заданные дни и часы сами, без запущенной сессии.
_Избегать_: режим по расписанию, автоблокировка

**Звуковой профиль**:
Набор фоновых звуков с громкостью каждого и общей громкостью; один выбирается для работы, другой — для отдыха. Не путать с пресетом таймера.
_Избегать_: звуковой пресет, сцена, плейлист, микс

**Пресет**:
Набор длительностей таймера: Focus, короткий перерыв, длинный перерыв и число Focus до длинного (например, 25/5/30×4). Встроенные нельзя изменить, свои можно создавать.
_Избегать_: шаблон, режим интервалов, профиль

**Активное время**:
Сколько времени сессия реально шла: от начала до конца за вычетом пауз и времени сна или выключения компьютера. Только оно идёт в статистику.
_Избегать_: отработанное время, чистое время, длительность

**Результат сессии**:
Что пользователь отметил после Focus по задаче: выполнено, частично, продолжить позже, отменить. Не путать с причиной завершения (закончилась, остановлена, пропущена и т. п.), которую фиксирует приложение само.
_Избегать_: исход, итог, статус сессии

**Восстановленная сессия**:
Сессия, которая продолжилась или была закрыта после сбоя, перезагрузки или перезапуска; время, пока приложение не работало, в неё не засчитывается как активное.
_Избегать_: возобновлённая, воскрешённая, продолженная после падения
