# Deep Focus

Таймер фокуса для Windows: плавающий виджет поверх окон, блокировка отвлекающих сайтов, фоновые звуки, задачи и аналитика. Всё хранится локально, телеметрии нет, права администратора не нужны.

## Установка

1. Соберите установщик (`npm ci`, затем `npm run dist`, см. «Разработка» ниже) или возьмите готовый `Deep Focus Setup <версия>.exe` из папки `release/`.
2. Запустите его. Установка идёт **для текущего пользователя**, запрос UAC не появляется; можно выбрать папку, создаются ярлыки на рабочем столе и в меню «Пуск».
3. Установщик не подписан: Windows SmartScreen покажет «Windows защитила ваш компьютер» — нажмите «Подробнее → Выполнить в любом случае» (см. [docs/limitations.md](docs/limitations.md)).
4. Удаление — «Параметры → Приложения». Деинсталлятор сначала запускает `Deep Focus.exe --cleanup`: блокировка снимается, настройки системного прокси возвращаются. Папка с данными остаётся; удалить её можно в приложении («Настройки → Общие → Удалить все данные») или вручную.

## Разработка

Нужны Node.js 24 и Git; Visual Studio и права администратора не нужны.

```
npm ci                    # зависимости строго по package-lock.json
npm run electron:install  # скачать Electron (иначе скачается при первом запуске)
npm run check             # типы, тесты, линтер
npm run build             # сборка в out/
npm run e2e               # e2e против собранного приложения
npm run dev               # запуск в режиме разработки
npm run dist              # установщик в release/
```

В сети с корпоративным сертификатом перед каждой командой npm задайте `NODE_OPTIONS=--use-system-ca` (Git Bash: `NODE_OPTIONS=--use-system-ca npm ci`; PowerShell: `$env:NODE_OPTIONS='--use-system-ca'`).

В `.npmrc` выключены install-скрипты зависимостей (`ignore-scripts=true`): better-sqlite3 поставляется с готовыми бинарниками, но npm по lock-файлу всё равно запустил бы для него `node-gyp rebuild`, а это требует Visual Studio. Другим зависимостям скрипты установки на Windows не нужны.

## Первый запуск

Откроется главное окно с разделом «Главная». Нажмите «Старт» — таймер запустится (по умолчанию Pomodoro 25/5), появится плавающий виджет. Задачу и блокировку выбирать не обязательно. Закрытие окна прячет приложение в трей (настраивается); полный выход — из меню трея.

## Разделы

- **Главная** — таймер, быстрый ввод задачи, прогресс целей, статус блокировки и звука, карточка «как прошла сессия».
- **Таймер** — режимы Pomodoro, секундомер и Deep Work без обязательных перерывов; пресеты (25/5, 45/10, 60/10, 90/20) и свои.
- **Звуки** — несколько дорожек одновременно, громкость каждой, общая громкость, пресеты, профили для работы и перерыва.
- **Блокировка** — правила по доменам (категории, свои домены, расписание), режимы Standard и Strict, статус и причина ошибки.
- **Задачи** — задачи и проекты, запуск таймера из задачи, учёт времени.
- **Аналитика** — время по дням, неделям и месяцам, проекты, продуктивные часы, цели, серия дней, точность учёта.
- **Настройки** — виджет, блокировка, звуки, уведомления, горячие клавиши, цели, тема и язык, автозапуск, обновления, данные.

## Горячие клавиши (глобальные, меняются в «Настройки → Общие»)

| Действие | По умолчанию |
|---|---|
| Старт / пауза | Ctrl+Alt+Space |
| Показать / скрыть виджет | Ctrl+Alt+W |
| Click-through (интерактивный режим) | Ctrl+Alt+I |
| Завершить сессию | Ctrl+Alt+E |
| Звук вкл / выкл | Ctrl+Alt+M |

Если сочетание занято другой программой, приложение скажет об этом. Click-through всегда можно выключить из трея и из главного окна.

## Куда класть mp3

Положите файлы в папку `assets/sounds/` (в установленном приложении — `resources\assets\sounds\` рядом с программой) с точными именами: `rain.mp3`, `rain-window.mp3`, `waves.mp3`, `wind.mp3`, `forest.mp3`, `birds.mp3`, `stream.mp3`, `river.mp3`, `thunderstorm.mp3`, `fireplace.mp3`, `coffee-shop.mp3`, `quiet-room.mp3`. Подробности — [assets/sounds/README.md](assets/sounds/README.md). Пока файла нет, звук виден в разделе «Звуки» с пометкой «файл не добавлен». Белый, розовый и коричневый шум создаёт само приложение. Свой звук (mp3, ogg, wav, m4a) добавляется кнопкой в разделе «Звуки»; копия лежит в папке данных. Используйте только записи, на которые у вас есть права.

## Где данные

- Данные и настройки: папка пользователя `%APPDATA%\Deep Focus\` (база `deepfocus.db`, свои звуки в `sounds\`). Путь виден в «Настройки → Общие → Данные», там же кнопка «Открыть папку».
- Журнал ошибок: `logs\deepfocus.log` в той же папке (ротация 1 МБ × 3).
- Резервная копия — экспорт и импорт в «Настройки → Общие → Данные».

## Обновления

Приложение проверяет обновления только по кнопке «Проверить обновления» и только в GitHub Releases. Пока владелец и репозиторий не указаны (`[GITHUB_OWNER]` / `[GITHUB_REPO]` в `electron-builder.yml` и `src/main/updater/source.ts`), кнопка пишет «источник не настроен» и в сеть ничего не отправляется. Скачивание — по кнопке, установка — при выходе из приложения.
